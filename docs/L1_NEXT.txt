Start the actual Linux2 pilot
-----------------------------
set +e
cd /ZPOOL/data/projects/istart-ds004920 &&
git pull --ff-only &&
bash code/start_l1.sh

This prepares a full frozen analysis inventory for both datasets, then runs four
activation pilots (one per dataset/task) and 24 seed-PPI pilots (the same four
runs x six seeds). It starts detached with ten concurrent run workers and
single-thread external tools. No review prompt or approval file is required.
Real feat_model designs, estimability, residual degrees of freedom, output maps,
grid geometry and smoothing are checked before success is recorded. A missing
or invalid run is reported; it is not assigned a scientific exclusion decision.

AFNI is located from existing RF1 processing-plan metadata and existing tool
directories. FSL commands are selected from the established FSLDIR installation.
No AFNI/FSL installation is performed. The existing .venv is reused, or created
from the preprocessing Python if absent; missing Python packages are installed
from requirements.txt. Preparation reads run images concurrently. Existing RF1
preprocessing and previous FEAT/TEDANA outputs remain unchanged.

The pilot starts activation spatial preparation and FEAT first. Seed extraction
and PPI follow verified activation outputs, reusing the same spatial products.
Condition-specific PPI, Win-minus-Loss PPI and the physiological main effect use
the authoritative rf1-sra-socdoors template at
b5520ee5e7d0659b80c2d4bb31334caaaa9cddbc. Double-gamma task convolution,
FEAT interaction settings and all five contrast vectors are preserved. Adapted
settings are dataset TR, common grid, total measured 6-mm smoothing, zero FEAT
smoothing, base-only nuisance inputs and Chloe's six seed assets.

The seed mean is extracted from UNSMOOTHED preprocessed BOLD on the common grid,
before statistical-model smoothing, preserving the order in legacy L1stats.sh.
Voxelwise FEAT uses the measured-6-mm image. No new physiological regression,
deconvolution, mask erosion or brain-mask intersection is introduced. Coverage
within each run's brain mask is recorded; partial coverage is flagged without a
new exclusion threshold. No overlap or a constant/nonfinite series fails that
seed model. The existing grid-only reslicing/template-space caveats remain in
masks/README.md. Left and right mPFC are primary; the other four seeds are
exploratory. Masks and models stay separate.
